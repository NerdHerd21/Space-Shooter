# Overview
This is a simple "Space Invaders" style shmup made with p5play.  
Programming, artwork, and music made entirely by me.  
This is a WIP, I will try to update semi-frequently.  

# Instructions to play:

#### From source code:
1.  Download and extract .zip file
2.  Open index.html in firefox or any chromium based browser
3.  You're done! Enjoy!

#### From website, no downloads required
1. Go to [this website](https://NerdHerd21.github.io/Space-Shooter).
